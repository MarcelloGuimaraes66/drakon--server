# Chaves de API

## Onde configurar

As chaves ficam em **Settings**.

## Para que servem

- **OpenAI**: habilita chat, agentes e jobs com recursos avançados de IA.
- **Z.ai**: habilita o modo Core.

## Como o app trata as chaves

O app deve informar apenas se a chave está configurada, sem expor o segredo completo.
