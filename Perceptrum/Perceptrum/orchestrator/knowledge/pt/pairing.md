# Pairing

## Como conectar o EXE

1. Abra **Settings** no site.
2. Gere um código de pareamento.
3. Use o código no EXE local.
4. Confirme se o status mudou para conectado.

## Regras importantes

- O código expira rapidamente.
- O pareamento liga a conta ao EXE daquela máquina.
- Em **Settings** você também pode verificar o status atual e desconectar.
