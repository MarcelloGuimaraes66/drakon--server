# Claves de API

## Dónde configurarlas

Las claves se administran en **Settings**.

## Para qué sirven

- **OpenAI**: habilita chat, agentes y jobs con funciones avanzadas.
- **Z.ai**: habilita el modo Core.

## Cómo las muestra la app

La app debe indicar solo si la clave está configurada, sin mostrar el secreto completo.
