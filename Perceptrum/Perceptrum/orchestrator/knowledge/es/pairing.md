# Pairing

## Cómo conectar el EXE

1. Abre **Settings** en el sitio.
2. Genera un código de emparejamiento.
3. Usa ese código en el EXE local.
4. Confirma que el estado cambió a conectado.

## Puntos importantes

- El código expira rápido.
- El emparejamiento vincula la cuenta con el EXE de esa máquina.
- En **Settings** también puedes revisar el estado y desconectar.
