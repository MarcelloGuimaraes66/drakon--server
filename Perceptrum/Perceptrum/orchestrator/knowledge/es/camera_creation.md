# Registro de Cámara

Usa **Cameras** cuando quieras registrar una cámara nueva, revisar la conexión o iniciar el servicio local.

## Flujo típico

1. Abre **Cameras**.
2. Crea una nueva cámara.
3. Completa nombre y descripción.
4. Ingresa IP, puerto, usuario, contraseña, canal y subtipo si hace falta.
5. Guarda la cámara.
6. Inicia el servicio local.
7. Verifica que la cámara aparezca online y actualizando frames o miniaturas.

## Lista rápida

- Revisa RTSP/IP, puerto y credenciales.
- Confirma que el EXE puede alcanzar el stream.
- Inicia el servicio antes de usar chat, agentes o jobs.
