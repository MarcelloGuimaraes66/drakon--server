# Pairing

## Comment connecter l'EXE

1. Ouvrez **Settings** sur le site.
2. Générez un code d'association.
3. Utilisez ce code dans l'EXE local.
4. Vérifiez que le statut passe à connecté.

## Points importants

- Le code expire rapidement.
- L'association relie le compte à l'EXE de cette machine.
- Dans **Settings**, vous pouvez aussi vérifier le statut et déconnecter.
