# Tutoriel

## Premiers pas

1. Générez un code d'association dans **Settings**.
2. Utilisez ce code dans l'EXE local.
3. Ajoutez vos caméras dans **Cameras**.
4. Démarrez le service local de chaque caméra.
5. Configurez les clés IA dans **Settings**.
6. Ensuite, créez des agents, des jobs ou utilisez le chat.

## Quand utiliser chaque zone

- **Chat** : questions sur l'application et recherche vidéo.
- **AI Agents** : surveillance continue par caméra.
- **Jobs** : routines planifiées et workflows à plusieurs étapes.
