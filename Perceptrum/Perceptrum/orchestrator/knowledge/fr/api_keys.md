# Clés API

## Où les configurer

Les clés se gèrent dans **Settings**.

## À quoi elles servent

- **OpenAI** : active le chat, les agents et les jobs avancés.
- **Z.ai** : active le mode Core.

## Comment l'application les affiche

L'application doit indiquer uniquement si la clé est configurée, sans exposer le secret complet.
