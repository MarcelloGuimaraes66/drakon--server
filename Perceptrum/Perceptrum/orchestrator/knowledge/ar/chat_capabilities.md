# قدرات Chat

يُعد Chat أسرع مكان لفهم المنتج، وقراءة الحالة الحالية للحساب، والبحث داخل الفيديو، وبدء الإجراءات الموجّهة بدون الحاجة إلى التنقل بين صفحات كثيرة.

## ما الذي يفيده Chat

- شرح كيفية عمل المنتج، وأين توجد الميزة داخل التطبيق، وأي تدفق أنسب للاستخدام.
- متابعة العمل عبر عدة رسائل بدون أن يضطر المستخدم إلى البدء من جديد كل مرة.
- جمع مساعدة المنتج، وقراءة الحالة الحية، والإجراءات الموجّهة في مكان واحد.

## المسارات المتخصصة للقدرات

خلف السلوك الحواري، يقوم Chat بتوجيه الطلب إلى قدرات متخصصة. لا يحتاج المستخدم إلى معرفة الأسماء الداخلية، لكن السلوك يتغير فعلاً بحسب نوع الطلب.

- المساعدة والتهيئة الأولى للمنتج: شرح pairing و API keys و billing وتسجيل الكاميرات و AI Agents و Jobs و Steps و orchestration ونظرة عامة على التطبيق و Chat نفسه.
- قراءة الحالة الحالية: عرض الكاميرات و jobs و agents والأرصدة والإعدادات والتنفيذات الأخيرة والسجل التشغيلي و identity cards المحفوظة عندما تكون هذه البيانات موجودة.
- فحص الفيديو والصور: البحث في كاميرا واحدة أو عدة كاميرات، وتحليل صورة أو فيديو مرفوع، والرد على أسئلة تتعلق بالتسجيلات أو الأحداث أو الاكتشافات عبر مسار البحث الحالي داخل الفيديو.
- الاكتشاف على الشبكة المحلية: تشغيل Scan Network من داخل Chat لاكتشاف الكاميرات و DVRs و NVRs ثم تلخيص النتيجة.
- عمليات الكاميرات: تسجيل كاميرا واحدة، وتحضير تسجيل دفعي لعدة كاميرات، وتعديل كاميرا واحدة، وتطبيق نفس التعديل على عدة كاميرات، وتشغيل أو إيقاف runtime لكاميرا موجودة.
- عمليات jobs: إنشاء jobs مجدولة و workflows متعددة steps، وتعديل job موجود، وتشغيل أو إيقاف أو إيقاف مؤقت أو استئناف runtime الخاص بـ job.
- عمليات agents: إنشاء أو تعديل agents على كاميرا أو داخل step من job، بما في ذلك الوجهة، والوتيرة، وتعديل prompt، والتفعيل أو التعطيل، و negative conditions، والتدفقات التي تحتاج إلى منطقة بصرية عند الحاجة.
- التقارير: إنشاء مستندات قابلة للتنزيل عن الحالة الحالية، والسجل، والاكتشافات، والتنبيهات، و jobs، و agents، و logs، والمقارنات، وسياق Chat المرتبط.
- الإجابة المباشرة: عندما لا توجد قدرة متخصصة أنسب، يستطيع Chat أن يجيب مباشرة بشكل طبيعي.

## كيف يدير Chat العمل عبر عدة رسائل

- يستطيع الاحتفاظ بمهمة نشطة عبر عدة رسائل بدلاً من التعامل مع كل رسالة كطلب جديد.
- يطلب الحقول الناقصة عندما يكون الطلب قابلاً للتنفيذ لكنه ما زال غير مكتمل.
- يفضّل التأكيد بدلاً من التخمين عندما يكون الهدف غير واضح.
- يفهم المتابعات مثل `استخدم نفس الشيء للخمس` و `هذه الكاميرا` و `نفس العنوان` و `الآن افعل نسخة الـ step`.
- في الأعمال الدفعية الخاصة بالكاميرات، يستطيع مواصلة جمع الصفوف والقيم المشتركة وقواعد التعديل عبر الحوار.

## الذاكرة والاتساق

- يستخدم Chat نوعين رئيسيين من ذاكرة المحادثة:
  1. turns حديثة للاستمرارية الفورية.
  2. سياقاً مدمجاً للاحتفاظ بالمعلومات الأقدم والأكثر دواماً.
- تحتفظ الذاكرة المدمجة بالحقائق المستقرة مثل الملخص، وأهداف المستخدم، والقيود، والتفضيلات، والكيانات المختارة، والقرارات، والنقاط المفتوحة.
- كما تحتفظ بذاكرة المهمة الخاصة بالعملية الحالية، بما في ذلك المهمة النشطة، والمرحلة، والهدف، والحقول التي تم جمعها، والحقول الناقصة، والمهام المكتملة مؤخراً.
- وتحافظ أيضاً على كيانات جلسة مهمة مثل آخر اسم أو id ذي صلة، حتى يسهل فهم المتابعات القصيرة.
- عندما تطول المحادثة كثيراً، يتم ضغط الرسائل الأقدم، وتبقى فقط الرسائل الأحدث بشكلها الحرفي.
- إذا كانت الرسالة الحالية تغيّر الموضوع بوضوح، فالأولوية تكون للرسالة الحالية.
- لا ينبغي للذاكرة المدمجة أن تحتفظ بأسرار مثل كلمات المرور أو API keys أو tokens أو RTSP URLs أو أي بيانات اعتماد خاصة أخرى.

## سلوك اللغة

- تم تنظيم Chat للعمل مع لغات الواجهة المدعومة: English و Portuguese و Spanish و French و Chinese و Arabic.
- يحاول الرد بلغة المستخدم.
- إذا كانت لغة المستخدم غير مدعومة، فإنه يعود إلى English بدلاً من تخمين لغة قريبة.
- قد يعود knowledge داخلياً إلى English، لكن يمكن إعادة صياغة الإجابة النهائية بلغة رد المستخدم.

## الضوابط والحدود المهمة

- يجب ألا يختلق Chat حالة حية. إذا كانت الإجابة تعتمد على الفحص، فعليه قراءة الحالة الحقيقية أولاً.
- يجب ألا يختلق Chat بيانات اعتماد الكاميرا أو IP أو المنفذ أو اسم المستخدم أو كلمة المرور أو العنوان إذا لم يقدّمها المستخدم.
- بعض الإجراءات تعتمد على runtime محلي متصل، وسياق جلسة Chat صالح، وبيانات موجودة داخل الحساب، والصلاحيات النشطة للمنتج.
- ينبغي أن تعتمد شروحات المنتج على مستندات knowledge المحلية عندما يكون ذلك هو الطريق الأكثر أماناً.
- يتم تنقيح الإجابات النهائية لتبقى موجزة ومركزة على المنتج وخالية من تفاصيل التنفيذ.

## أمثلة جيدة على الأسئلة

- `ماذا يستطيع chat أن يفعل؟`
- `ما الذي يمكنك فعله هنا؟`
- `اعرض لي أنواع الأشياء التي يساعدني فيها chat`
- `هل يمكنك فحص الكاميرات والjobs الخاصة بي من هنا؟`
- `هل يمكنك إنشاء أو تعديل الكاميرات أو agents أو jobs؟`
- `كيف تحافظ على السياق بين الرسائل؟`
- `ما حدودك؟`

## قاعدة عملية

- استخدم Chat عندما يريد المستخدم واحداً من هذه الأمور الثلاثة:
  1. شرحاً موثوقاً عن المنتج.
  2. قراءة أو بحثاً يتعلق بالحالة الحالية أو السجل أو الفيديو.
  3. إجراءً موجهاً يمكن أن يستمر عبر عدة رسائل إلى أن يتم تأكيده أو إكماله.
