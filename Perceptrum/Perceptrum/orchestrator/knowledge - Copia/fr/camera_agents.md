# Agents de caméra

Un agent de caméra s'exécute en continu sur une caméra spécifique.

## Quand l'utiliser

- surveillance continue,
- alertes automatiques,
- règles toujours actives hors du chat.

## Configuration habituelle

- caméra cible,
- prompt de l'agent,
- conditions d'alerte,
- comportement de capture.

## Exemple

Créer un agent pour le parking et alerter lorsqu'une personne est détectée hors des heures d'ouverture.
