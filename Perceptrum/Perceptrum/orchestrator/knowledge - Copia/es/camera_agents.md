# Agentes de Cámara

Un agente de cámara se ejecuta continuamente sobre una cámara específica.

## Cuándo usarlo

- monitoreo continuo,
- alertas automáticas,
- reglas activas fuera del flujo del chat.

## Configuración habitual

- cámara objetivo,
- prompt del agente,
- condiciones de alerta,
- comportamiento de captura.

## Ejemplo

Crear un agente para el estacionamiento y alertar cuando se detecten personas fuera del horario comercial.
