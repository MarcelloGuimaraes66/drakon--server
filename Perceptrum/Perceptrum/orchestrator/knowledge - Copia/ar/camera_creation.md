# إنشاء كاميرا

استخدم **Cameras** عندما تريد إضافة كاميرا جديدة أو مراجعة بيانات الاتصال أو تشغيل الخدمة المحلية.

## التدفق المعتاد

1. افتح **Cameras**.
2. أنشئ كاميرا جديدة.
3. أدخل الاسم والوصف.
4. أضف عنوان IP والمنفذ واسم المستخدم وكلمة المرور والقناة والنوع الفرعي عند الحاجة.
5. احفظ الكاميرا.
6. شغّل الخدمة المحلية.
7. تأكد أن الكاميرا تظهر كمتصلة وأن الصور المصغرة أو الإطارات تتحدث.

## فحص سريع

- راجع RTSP/IP والمنفذ وبيانات الدخول.
- تأكد أن EXE يستطيع الوصول إلى البث.
- شغّل الخدمة قبل استخدام الدردشة أو الوكلاء أو الوظائف.
