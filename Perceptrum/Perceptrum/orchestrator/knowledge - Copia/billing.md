# Billing

The Billing page covers three main things:

- Chat tokens: buy token balance for chat and AI usage.
- Subscriptions: create or manage recurring camera plans with model tier, camera count, and seconds-per-frame settings.
- Payment methods and history: save cards, cancel a subscription, remove cards, and review payments.

Current chat access rules in the app:

- Chat and video search are allowed when the account has an active subscription, token balance, or an active payment method.
- Billing status is also used before adding paid camera AI capacity.

The dashboard shows token balance, payments, and the latest active subscription. Subscriptions store fields such as subscription_type, model_tier, camera_count, seconds_per_frame, started_at, and expires_at.
