Objetivo:
Ler o repositório drakon-server neste computador Ubuntu, entender a estrutura atual e conectar o Archon/Codex ao projeto para iniciar o desenvolvimento em fases.

O sistema drakon-server será um programa CLI/headless, sem interface gráfica, responsável por:
- ler banco/configuração;
- conectar câmeras RTSP/ONVIF;
- capturar frames em 1 FPS, 10 FPS ou perfis configuráveis;
- criar diretórios por câmera e timestamp;
- salvar imagens/frames;
- rodar inferências;
- salvar resultados em JSON estruturado;
- gerar alertas JSON;
- criar índices JSONL para o dashboard Drakon;
- permitir que o dashboard leia os arquivos gerados.
