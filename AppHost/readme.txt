========================================================================
    Drakon-Perceptrum Desktop Scaffold
========================================================================

This project is the initial WinUI 3 + C++/WinRT scaffold for the unified
desktop migration of:

  - C:\dev\DrakonSite
  - C:\dev\perceptrum_app

Current goal of this first cut:

  1. Establish the new project root in C:\dev\Drakon-Perceptrum
  2. Create a native WinUI 3 desktop shell
  3. Prepare the initial Fluent resource dictionaries
  4. Provide the base window that will host the future XAML pages

Next implementation targets:

  - LoginPage.xaml
  - DashboardPage.xaml
  - Real navigation service
  - SQLite local persistence bootstrap
  - Integration of runtime modules from perceptrum_app
